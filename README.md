# Visuomotor_Control_Tasks
A series of fine motor control tasks for Psychology and Cognitive Neuroscience research. This also includes preprocessing scripts for all outputted data. Please consider citing my research if you use these scripts in an academic setting. 

To run these scripts you will need to download Psychtoolbox seperately - https://psychtoolbox.org/ 

REFERENCES:

1. Beech, S., Stanton Fraser, D., Corston-Petrie, A., Gower, A. P., & Gilchrist, I. D. (2024). How changes in the mean latency, jitter amplitude, and jitter frequency impact target acquisition performance. ACM Transactions on Applied Perception, 22(2), 1-18.

2. Beech, S., Fraser, D. S., & Gilchrist, I. D. (2025). Visuomotor adaptation to constant and varying delays in a target acquisition task. Journal of Vision, 25(6), 8-8.
